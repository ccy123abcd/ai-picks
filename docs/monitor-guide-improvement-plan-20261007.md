# 显示器品类改版方案（2026-10-07，来自真实用户对话）

## 背景
用户 Easy 在 2026-10-07 晚间的真实选购对话，完整走了一遍购买决策链：
查捡漏 → 质疑"全新未拆盒"老机器 → 查年份验真伪 → 问寿命（怕买到只剩 2 年寿命）
→ IPS vs OLED → 质疑"两三百的新 OLED" → 要求查 34 寸 OLED 各牌子行情 → VA vs IPS。
结论：**参数太多、预算各异、用途不同（游戏/办公/画图），用户要的不是参数表，是"按我的情况直接告诉我买谁"。**

## 改版清单

### 1. 按用途选（最高优先级）
每个显示器指南顶部加"用途速配"：
- 打游戏：看刷新率 + 响应时间（OLED 0.03ms / IPS 4ms / VA 暗部拖影警告）
- 办公：看文字清晰度（RGB 条纹子像素）、护眼（DC 调光/低蓝光）、27 寸以上别买 1080p
- 设计画图：看色准 ΔE<2、色域覆盖、IPS 优先，VA 色偏警告

### 2. 预算锚点
每档预算只推 1 个"闭眼买"：
- $250 档二手：Alienware AW3418DW（IPS 120Hz）> Samsung C34J791（VA 100Hz，2018 老库存）
- $800+：34 寸 OLED 入门（LG 34GX900A-B 促销 $700）
- 直接写明"两三百买不到新 34 寸 OLED，别信"

### 3. 二手避坑专区（新栏目）
- 查年份：2018 年的老机器，LED 背光寿命 3~6 万小时，按每天 8 小时 ≈ 10 年
- "全新未拆盒"老库存：可能是真的（经销商压货），但按二手价买、当面拆箱点亮验
- 验货清单：纯白图看发黄/亮度不均，纯黑图看漏光，最高亮度是否还够
- VA 冒充 OLED、1080p 冒充 2K 这类骗局点名

### 4. 参数说人话（已有 53 条术语库，补显示器专项）
- 对比度 1000:1 vs 3000:1 vs 无限：黑画面发灰 vs 纯黑
- 响应时间 4ms vs 0.03ms：拖影
- 烧屏：OLED 长期静态画面（任务栏）会烧，IPS 不会
- 曲率 1500R/1800R：数字越小越弯

### 5. VA vs IPS 一句话卡（放指南顶部）
| | VA | IPS |
|---|---|---|
| 对比度 | 3000:1，黑更纯，看电影好 | 1000:1，黑发灰 |
| 可视角度 | 侧面发白偏色 | 178° 无色偏 |
| 响应 | 慢，暗部拖影 | 快 |
| 色准 | 艳但不准 | 准，设计首选 |
| 价格 | 同规格更便宜 | 贵一点 |
| 适合 | 看片、便宜大碗 | 游戏、办公、画图 |

### 6. 决策工具（后续）
预算 × 用途 → 直接出推荐，quiz 形式，3 步出结果。
